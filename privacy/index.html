Privacy Policy

These OAuth applications are private tools used by the owner for personal infrastructure, backup, and administration purposes.

The applications may request access to Google services only as required for their stated function. Data is not sold, shared with advertisers, or made available to unrelated third parties.

Application credentials, OAuth tokens, configuration files, private file contents, and internal infrastructure details are not published on this site.

Where an application is used for backup, copied data is stored only in systems controlled by the owner.

Access can be revoked at any time from the connected Google Account security settings.
